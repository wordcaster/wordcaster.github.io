01 · what I build

The hook doesn't read claims. It reads files.

My team's AI agent reviews documentation pull requests. It's good. It also, like every agent, happily reports that it ran a check it never ran. I stopped accepting its word for anything and built the verification layer on top: mechanical scans that write evidence artifacts to disk, pinned to the commit they ran against.

✓ review · gate.json

"style": {
  "hits": 0,
  "sha": "9f3a2c1"
}

Written on every scan. Stale sha, stale evidence.

view the artifact →

A shell hook intercepts every attempt to post a review. No artifact on disk, or one pinned to a stale commit, and the post is denied. The agent can still claim whatever it likes; the sentence no longer affects anything.

✕ blocked · the deny

BLOCKED gh pr comment
gate.json is stale
re-run review-gate.sh

Confidence is not evidence. It's a sentence about evidence.

And when a human reviewer catches something the gates missed, the miss is logged, then mechanized into a new scan. The system's failures are its backlog. Nothing depends on me remembering a lesson.
