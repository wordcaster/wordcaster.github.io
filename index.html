What I build

My team's AI agent reviews documentation pull requests. It's good. It will also, like every agent, happily report that it ran a check it never ran. I stopped accepting its word for anything and evidenceThe layer is mine; the agent tooling under it is my team's. The full story, including what failed first: Checkbox theater: how I stopped trusting my AI agent to run the checks: mechanical scans that write evidence artifacts to disk, a shell hook that blocks the agent from posting a review until those artifacts exist and match the current commit, and a gap log that turns every missed catch into a new automated check. The agent can still claim whatever it likes. The hook doesn't read claims. It reads files.
